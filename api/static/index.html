🔥 EmberRisk — Wildfire Risk Prediction

A locked HistGradientBoostingClassifier (threshold 0.70) predicting whether a location will experience a wildfire within the next 7 days.
Scope note: this model was trained and evaluated on a fixed historical period (2018–2025). This demo scores either a real historical row from that period, or hypothetical values you enter — it does not predict live/current fire risk. See the project README for full methodology and results.
